# Retro Cable Box

A small box for your TV that turns the media you point it at into a 24-hour
retro cable lineup. Your AI agent programs the channels.

![The channel guide](assets/guide.png)

## What it does

- **A real cable lineup.** Every channel runs on a shared clock. When you tune
  in, the show is already in progress, like real TV.
- **A 90s channel guide.** A scrolling grid, a preview window, an info banner,
  channel numbers and a clock.
- **Your agent programs it.** The box has an MCP server. Any MCP client
  (Claude, ChatGPT, Cursor, a local model) can build channels, schedule
  shows, add pop-up trivia and post notices.
- **Public domain first.** The starter lineup comes from archive.org and NASA.
  Add your own video files, or live channels from an IPTV playlist.
- **Plugins.** The box knows no streaming service. Plugins from GitHub repos
  add services and channels, and their releases bring updates.
- **Your TV remote.** HDMI-CEC turns the TV remote into the cable remote. A
  USB IR receiver works with any other remote.
