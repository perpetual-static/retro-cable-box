# Case files

Put the printable case files here: `.stl`, `.3mf` and `.step`. The docs site
lists every file in this folder on its Build page, with a download link, so a
new file is published on the next docs build.

Name the files by part, for example `case-body.stl`, `case-lid.stl`,
`led-bezel.stl`. Put print settings in `PRINTING.md` in this folder.
