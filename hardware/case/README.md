# Case files

| File | What it is |
| --- | --- |
| `case-cover.stl` | The U-shaped cover (top and sides) with a wood-grain surface |
| `case-body.stl` | Floor, faceplate with the LED window, back panel, Pi standoffs |
| `generate.py` | Makes both STL files (Python, manifold3d) |
| `woodgrain.py` | The procedural wood grain |
| `PRINTING.md` | Print settings and assembly |

The docs site lists every file in this folder on its Build page, with a
download link, so a new file is published on the next docs build.
